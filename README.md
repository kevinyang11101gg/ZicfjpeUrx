# Python图书管理系统（源码+8k字开发文档）

## 核心功能
- 登录注册
- 浏览图书
- 图书管理
- 分类管理
- 用户管理
- 借阅管理
- 个人信息修改

## 适用场景
- 学校图书馆
- 公司图书室
- 个人图书管理

## 技术特点
- 使用Django框架进行开发
- 数据库采用MySQL
- 前端采用HTML、CSS、JS等技术
